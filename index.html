Smart Checklist

    Load checklist workbook

    Upload a setup .zip containing your checklist workbook (.xlsx) at the root and an Examples subfolder of the PDFs and images its Example column references. A bare .xlsx also works (no examples). Nothing is uploaded — everything stays in your browser.

    Appearance

    Dark mode
    Switch between light and dark appearance.
    Colour completed items
    Tint checklist items green when done and amber when partly done. The checkbox and unit tags stay coloured either way.

    Backup

    Save Project Library
    Download a single file with every project and all its units. Keep it somewhere safe in case browser data is cleared.
    Auto-save to a file
    Connect a backup file (e.g. in OneDrive) and your work saves to it automatically, surviving a browser-data wipe.
